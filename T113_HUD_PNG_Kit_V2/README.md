## C 端叠加建议

- 启动阶段一次性解码 PNG 为预乘 alpha 的 ARGB8888，并常驻可复用缓冲区；不要逐帧解码。
- 合成顺序：摄像头 → 静态框/面板 → fill → 图标 → 动态文字。
- RPM：按 `rpm / rpm_max` 计算横向可见宽度；若希望严格按格推进，量化为素材中的分段数。
- 踏板：源和目标矩形均从底部对齐，按输入比例改变裁剪高度。
- G 点：建议有效半径 52～58 px，超范围时钳位，不要让光点越过外环。
- `preview_composite.png` 保留示意数字，其他动态文本承载层均已清空实时值。
